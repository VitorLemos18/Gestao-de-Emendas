# Gestão de Emendas

Aplicação para cadastro e acompanhamento de emendas parlamentares.

- `frontend/`: interface Angular.
- `backend/`: API Spring Boot, migrações PostgreSQL e configuração do serviço.

Consulte os READMEs de cada pasta para as instruções de execução. Arquivos locais de configuração, como `.env`, dependências instaladas, dados e artefatos de compilação não fazem parte desta cópia.

Para implantação de produção em Ubuntu/Docker com HTTPS, consulte [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
